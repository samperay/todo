# Roadmap — v3

1. **01–02:** Trace application and resilience boundaries.
2. **03–04:** Queues, event contracts, SQLite transactions and optional outbox.
3. **05–08:** Linux, networking, containers and CI/CD.
4. **09–12:** IaC, Kubernetes, advanced Kubernetes and cloud architecture.
5. **13–18:** Observability, SLOs, performance, security, distributed systems and disaster recovery.
6. **19–20:** AI-assisted operations and an evidence-based architecture capstone.

**Completion rule:** A lesson is not completed until the learner explains the concept, runs a safe lab, records output and discusses failure/recovery. Running one module experiment does not complete all lessons.

**Implementation rule:** For real Todo changes, use Spec-Driven Development: spec → plan → tasks → tests → code → CI → PR → review → rollback.
