# Handbook V2 validation and scope

- 20 module READMEs, 230 lesson guides, 20 runnable Python standard-library experiments.
- Every lesson has an exact invocation, a topic-specific question set, a failure/recovery exercise, and correct relative links.
- Module experiments are **shared foundations**: they do not replace a full live-service integration lab for each lesson.
- External services (Docker, Terraform, Kubernetes, cloud) are optional and reported as SKIP until configured.
- Never claim that a simulated experiment proves a deployed feature.
- To check the package: run `python3 tutorials/sre-devops-architect-handbook/validate_handbook.py` from the repository root.
