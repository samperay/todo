# Glossary

- **Producer:** Component that publishes work.
- **Consumer:** Component that retrieves and processes work.
- **Queue:** Buffer between producers and consumers.
- **FIFO:** First in, first out.
- **Backlog:** Work waiting to be processed.
- **Idempotency:** Repeating an operation has no additional intended effect.
- **Outbox:** Durable table of events committed with application state.
- **SLO:** Measurable reliability target.
- **RPO:** Maximum acceptable data loss window.
- **RTO:** Target recovery time after an incident.
- **ADR:** Architecture decision record.
