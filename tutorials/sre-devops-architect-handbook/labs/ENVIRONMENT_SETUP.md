# Environment setup

- Python 3.10+ recommended; only Python standard library is needed for the included module experiments.
- Execute commands from the **Todo repository root**, unless the lesson says otherwise.
- `python3 tutorials/sre-devops-architect-handbook/labs/module-experiments/module-03.py --list` verifies the installation.
- Use disposable local examples. Never run destructive failure drills on production.
- Docker, Kubernetes, Terraform and cloud are optional future prerequisites, not requirements for offline models.
